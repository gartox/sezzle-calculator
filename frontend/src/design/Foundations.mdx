# Foundations

Every color, size and duration in the calculator comes from `src/design/tokens.css`. The light theme is the default and the dark theme follows `prefers-color-scheme`; both are shown side by side below. Contrast ratios are computed live from the resolved tokens, so a change that drops a pair below WCAG AA shows up here immediately and fails the accessibility test of these stories.
